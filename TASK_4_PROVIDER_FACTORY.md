# Задача 4: Создание фабрики провайдеров

## Название задачи
Создание ProviderFactory и системы управления провайдерами

## Описание задачи
Создать фабрику для управления различными провайдерами Кинопоиска, которая будет:
- Создавать экземпляры провайдеров
- Управлять переключением между провайдерами
- Обеспечивать отказоустойчивость
- Предоставлять единый интерфейс для работы с любым провайдером

## Чек-лист выполнения задачи
- [ ] Создать `ProviderFactory` класс
- [ ] Реализовать методы создания провайдеров
- [ ] Добавить логику переключения провайдеров
- [ ] Реализовать fallback механизм
- [ ] Создать `ProviderManager` для управления активным провайдером
- [ ] Добавить кэширование провайдеров
- [ ] Реализовать проверку доступности провайдеров

## Функциональность фабрики
1. **Создание провайдеров**
   - Создание экземпляров по типу провайдера
   - Передача конфигурации
   - Валидация настроек

2. **Управление провайдерами**
   - Переключение между провайдерами
   - Проверка статуса провайдеров
   - Автоматический fallback при ошибках

3. **Отказоустойчивость**
   - Retry логика
   - Переключение на резервный провайдер
   - Логирование ошибок

## Файлы для создания
1. `src/shared/services/providers/provider-factory.ts` - Фабрика провайдеров
2. `src/shared/services/providers/provider-manager.ts` - Менеджер провайдеров
3. Обновить `src/shared/services/providers/index.ts`

## Интеграция с настройками
- Чтение выбранного провайдера из настроек
- Получение API ключей для каждого провайдера
- Сохранение предпочтений пользователя
