# Документация: Автоматическая установка фильтра типа контента

## Описание функциональности

Реализована функциональность автоматической установки и блокировки фильтра "Тип" на странице поиска при выборе категории контента в боковом меню.

## Как это работает

### 1. Выбор категории в боковом меню
При клике на категорию в боковом меню (Фильмы, Сериалы, Аниме):
- Происходит навигация на страницу поиска
- Автоматически устанавливается соответствующий тип контента
- Фильтр "Тип" блокируется для редактирования
- Изменяется заголовок страницы

### 2. Mapping категорий на типы контента
- `movies` → `movie` (Фильмы)
- `series` → `tv-series` (Сериалы)
- `anime` → `anime` (Аниме)

### 3. Динамические заголовки
- **Фильмы**: "Поиск фильмов" / "Найдите интересные фильмы"
- **Сериалы**: "Поиск сериалов" / "Найдите интересные сериалы"
- **Аниме**: "Поиск аниме" / "Найдите интересные аниме"
- **По умолчанию**: "Поиск фильмов" / "Найдите интересные фильмы и сериалы"

## Особенности реализации

### Автоматическая установка типа
```typescript
// Автоматически устанавливаем тип контента при изменении contentType
$: if (contentType && contentType !== selectedType) {
  selectedType = contentType;
  if (apiKeyConfigured && hasSearched) {
    handleSearch();
  }
}
```

### Блокировка фильтра
```typescript
// Блокируем фильтр типа если задана категория
$: isTypeFilterDisabled = !!contentType;
```

### Умная очистка фильтров
```typescript
function clearFilters() {
  searchQuery = '';
  selectedGenre = '';
  // Не очищаем selectedType если он задан через категорию
  if (!isTypeFilterDisabled) {
    selectedType = '';
  }
  selectedYear = '';
  // ... остальная логика
}
```

## Пользовательский опыт

1. **Интуитивность**: Пользователь видит, что фильтр автоматически установлен в соответствии с выбранной категорией
2. **Визуальная обратная связь**: Заблокированный select имеет соответствующие стили
3. **Сохранение контекста**: При очистке фильтров тип контента остается установленным
4. **Динамические заголовки**: Четко показывают, в какой категории происходит поиск

## Тестирование

Для тестирования функциональности:
1. Откройте боковое меню
2. Кликните на любую категорию (Фильмы, Сериалы, Аниме)
3. Убедитесь, что:
   - Заголовок изменился соответственно
   - Фильтр "Тип" установлен и заблокирован
   - При нажатии "Очистить" тип остается установленным
   - Поиск работает с учетом выбранного типа
