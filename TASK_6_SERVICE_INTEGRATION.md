# Задача 6: Интеграция с существующим сервисом

## Название задачи
Обновление существующего KinopoiskService для использования ProviderManager

## Описание задачи
Обновить существующий файл `kinopoisk.ts` для использования нового `ProviderManager` вместо прямого обращения к API. Это обеспечит:
- Использование выбранного провайдера из настроек
- Автоматический fallback при ошибках
- Единый интерфейс для всех компонентов приложения
- Обратную совместимость

## Изменения в KinopoiskService
1. **Замена прямых API вызовов**
   - Использовать ProviderManager вместо fetch
   - Делегировать все методы в ProviderManager

2. **Инициализация**
   - Создать метод `initialize()` для настройки ProviderManager
   - Автоматическая инициализация из настроек

3. **Управление провайдерами**
   - Методы для переключения провайдеров
   - Получение статуса провайдеров
   - Обновление конфигурации

4. **Обратная совместимость**
   - Сохранить существующие методы
   - Поддержка legacy API
