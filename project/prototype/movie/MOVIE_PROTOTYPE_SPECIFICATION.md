# Техническое задание: Прототип приложения поиска фильмов GeekHeaven

## Описание проекта

Прототип веб-приложения для поиска фильмов, управления личными коллекциями, отметок о просмотре и получения рекомендаций. Данные сохраняются локально на устройстве пользователя с возможностью экспорта/импорта. Для получения информации о фильмах используется Kinopoisk API Unofficial.

## Основные функции

### 1. Настройка приложения
- **Ввод API ключа**: Пользователь вводит свой API ключ от Kinopoisk API
- **Валидация ключа**: Проверка работоспособности через тестовый запрос
- **Сохранение настроек**: Ключ сохраняется в LocalStorage
- **Управление ключом**: Возможность изменить ключ в настройках
- **Первоначальная настройка**: Экран приветствия с инструкциями

### 2. Система поиска фильмов
- Поиск по названию фильма с debounce (300ms)
- Фильтрация по жанрам, годам, рейтингу, стране
- Сортировка результатов (по рейтингу, году, популярности)
- Отображение результатов в виде карточек с постерами
- Детальная информация о фильме (описание, актеры, режиссер, рейтинг)
- Пагинация с ленивой загрузкой
- Сохранение истории поисков

### 3. Управление коллекциями
- Добавление фильмов в личные коллекции
- Создание пользовательских списков ("Любимые", "К просмотру", "Просмотрено")
- Удаление фильмов из коллекций
- Экспорт/импорт коллекций в JSON формате
- Поиск внутри коллекций

### 4. Отметки о просмотре
- Отметка фильма как "Просмотрено"/"Не просмотрено"
- Личная оценка фильма (1-10 звезд)
- Дата просмотра
- Личные заметки к фильму
- Статистика просмотров (общее количество, по жанрам)
- Время просмотра (опционально)

### 5. Комментарии и отзывы
- Написание личных отзывов к фильмам
- Редактирование и удаление отзывов
- Сохранение отзывов в локальном хранилище
- Теги для категоризации
- Поиск по заметкам

### 6. Рекомендации
- Рекомендации на основе просмотренных и оцененных фильмов
- Популярные фильмы (топ-100)
- Новинки кинематографа
- Фильмы по жанрам
- Персональные подборки

## Работа с Kinopoisk API Unofficial

### Базовый URL
```
https://kinopoiskapiunofficial.tech/api/
```

### Необходимые эндпоинты

#### 1. Поиск фильмов по ключевому слову
```
GET /v2.1/films/search-by-keyword
Headers: X-API-KEY: YOUR_API_KEY
Params: 
  - keyword: string (название фильма)
  - page: number (номер страницы, по умолчанию 1)
```

#### 2. Получение информации о фильме
```
GET /v2.2/films/{id}
Headers: X-API-KEY: YOUR_API_KEY
Params:
  - id: number (ID фильма)
```

#### 3. Получение топ фильмов
```
GET /v2.2/films/top
Headers: X-API-KEY: YOUR_API_KEY
Params:
  - type: string (TOP_100_POPULAR_FILMS, TOP_250_BEST_FILMS)
  - page: number
```

#### 4. Фильтрация фильмов
```
GET /v2.2/films
Headers: X-API-KEY: YOUR_API_KEY
Params:
  - genres: number (ID жанра)
  - order: string (RATING, NUM_VOTE, YEAR)
  - type: string (FILM, TV_SERIES)
  - ratingFrom: number (от 0 до 10)
  - ratingTo: number (от 0 до 10)
  - yearFrom: number
  - yearTo: number
  - page: number
```

#### 5. Получение жанров и стран
```
GET /v2.2/films/filters
Headers: X-API-KEY: YOUR_API_KEY
```

### Получение API ключа
1. Зарегистрироваться на https://kinopoiskapiunofficial.tech/
2. Получить бесплатный API ключ (лимит: 500 запросов в день)
3. Добавить ключ в конфигурацию приложения

### Пример запроса
```javascript
const API_KEY = 'YOUR_API_KEY';
const BASE_URL = 'https://kinopoiskapiunofficial.tech/api';

async function searchMovies(keyword) {
  const response = await fetch(`${BASE_URL}/v2.1/films/search-by-keyword?keyword=${keyword}`, {
    headers: {
      'X-API-KEY': API_KEY,
      'Content-Type': 'application/json'
    }
  });
  
  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }
  
  return await response.json();
}
```
