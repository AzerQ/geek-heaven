# Задача 5: Обновление настроек приложения

## Название задачи
Обновление системы настроек для поддержки выбора провайдера Кинопоиска

## Описание задачи
Обновить систему настроек приложения для поддержки:
- Выбора активного провайдера Кинопоиска
- Ввода API ключей для каждого провайдера
- Настройки fallback провайдеров
- Управления конфигурацией провайдеров

## Чек-лист выполнения задачи
- [ ] Обновить интерфейс `AppSettings`
- [ ] Добавить новые поля для провайдеров
- [ ] Обновить функции загрузки/сохранения настроек
- [ ] Добавить валидацию настроек провайдеров
- [ ] Создать миграцию существующих настроек
- [ ] Обновить UI настроек
- [ ] Интегрировать с ProviderManager

## Новые поля настроек
1. **selectedKinopoiskProvider** - выбранный провайдер
2. **kinopoiskProviders** - конфигурация провайдеров
3. **fallbackProviders** - список резервных провайдеров
4. **providerRetryAttempts** - количество попыток
5. **providerHealthCheckInterval** - интервал проверки здоровья

## Структура конфигурации провайдеров
```typescript
interface KinopoiskProviderSettings {
  [ProviderType.KINOPOISK_DEV]: {
    apiKey: string;
    enabled: boolean;
  };
  [ProviderType.UNOFFICIAL]: {
    apiKey: string;
    enabled: boolean;
  };
}
```
