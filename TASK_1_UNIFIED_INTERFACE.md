# Задача 1: Создание унифицированного интерфейса

## Название задачи
Создание унифицированного интерфейса для провайдеров Kinopoisk

## Описание задачи
Создать общий интерфейс `IKinopoiskProvider`, который будет реализован всеми провайдерами кинопоиска. Это обеспечит единообразный API для работы с разными источниками данных.

## Чек-лист выполнения задачи
- [ ] Создать файл `src/shared/services/providers/types.ts` с общими типами
- [ ] Определить интерфейс `IKinopoiskProvider` с базовыми методами
- [ ] Создать абстрактный класс `BaseKinopoiskProvider`
- [ ] Добавить типы для конфигурации провайдеров
- [ ] Создать enum для типов провайдеров
- [ ] Добавить интерфейсы для ошибок и валидации

## Файлы для создания
1. `src/shared/services/providers/types.ts` - Общие типы и интерфейсы
2. `src/shared/services/providers/base-provider.ts` - Базовый абстрактный класс
3. `src/shared/services/providers/index.ts` - Экспорты
