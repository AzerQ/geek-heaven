## Технические детали

### API Endpoint
- Базовый URL: `https://api.kinopoisk.dev/v1.4`
- Endpoint изображений: `/image`
- Параметры: movieId, page, limit, type

### Типы изображений
- `poster` - постеры
- `backdrop` - фоновые изображения
- `screenshot` - скриншоты
- `frame` - кадры из фильма

### Компоненты
1. `MediaGallery.svelte` - основной компонент галереи
2. `ImageModal.svelte` - модальное окно для просмотра
3. `ImageGrid.svelte` - сетка изображений
4. `ImagePreview.svelte` - превью изображения
