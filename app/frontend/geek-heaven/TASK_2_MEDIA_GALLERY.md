# Задача 2: Создание компонента MediaGallery

## Название задачи
Создание компонента MediaGallery для отображения изображений

## Описание задачи
Создать модульный компонент для отображения галереи изображений с модальным окном просмотра

## Чек-лист выполнения задачи
- [ ] Создать базовый компонент MediaGallery.svelte
- [ ] Создать компонент ImageModal.svelte для модального просмотра
- [ ] Создать компонент ImageGrid.svelte для сетки изображений
- [ ] Добавить навигацию между изображениями
- [ ] Реализовать lazy loading
- [ ] Добавить обработку ошибок загрузки
- [ ] Создать адаптивную верстку

## Компоненты
1. MediaGallery.svelte - основной компонент
2. ImageModal.svelte - модальное окно
3. ImageGrid.svelte - сетка изображений
4. ImagePreview.svelte - превью изображения
