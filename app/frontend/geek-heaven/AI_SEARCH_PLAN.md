## Технические детали

### OpenRouter API
- Базовый URL: `https://openrouter.ai/api/v1`
- Endpoint: `/chat/completions`
- Модель: `anthropic/claude-3.5-sonnet` (рекомендуемая для анализа текста)
- Формат ответа: JSON с предложениями фильмов

### Структура промпта
```
Пользователь описал фильм: "{описание}"

Проанализируй описание и предложи 3-5 наиболее подходящих фильмов.
Ответь в формате JSON:
{
  "suggestions": [
    {
      "title": "Название фильма",
      "type": "movie|tv-series|cartoon|anime",
      "description": "Краткое описание (1-2 предложения)",
      "confidence": 0.95
    }
  ]
}
```

### Компоненты
1. `AISearch.svelte` - основной компонент AI поиска
2. `MovieSuggestionCard.svelte` - карточка предложения фильма
3. `openrouter.ts` - сервис для работы с OpenRouter API
4. Обновленный `settings.ts` - добавление OpenRouter API ключа

### Интерфейсы
```typescript
interface MovieSuggestion {
  title: string;
  type: 'movie' | 'tv-series' | 'cartoon' | 'anime';
  description: string;
  confidence: number;
}

interface AISearchResponse {
  suggestions: MovieSuggestion[];
}

interface OpenRouterRequest {
  model: string;
  messages: Array<{
    role: 'user' | 'assistant' | 'system';
    content: string;
  }>;
  max_tokens?: number;
  temperature?: number;
}
```
