# Задача 1: Интеграция с API изображений

## Название задачи
Интеграция с Kinopoisk API для получения изображений

## Описание задачи
Расширить существующий сервис Kinopoisk для работы с изображениями (постеры, скриншоты, кадры, фоны)

## Чек-лист выполнения задачи
- [ ] Создать интерфейсы для изображений
- [ ] Добавить метод getMovieImages в KinopoiskService
- [ ] Добавить типы для различных видов изображений
- [ ] Добавить обработку ошибок
- [ ] Протестировать API интеграцию

## Технические детали
- API endpoint: `/image`
- Параметры: movieId, page, limit, type
- Типы изображений: cover, backdrops, screenshot, frame
